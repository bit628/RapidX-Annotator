# Security Policy

RapidX Annotator is currently distributed as a research source release and does not yet have a stable supported release line. Security-related fixes, when available, target the current `main` branch.

## Reporting a vulnerability

Please do **not** disclose suspected vulnerabilities, credentials, private data, or exploit details in a public GitHub issue.

Use GitHub's private vulnerability reporting channel:

- [Privately report a security vulnerability](https://github.com/bit628/RapidX-Annotator/security/advisories/new)

If that interface is unavailable, contact the maintainers through the [research group website](http://znhj.tz-ndt.com/) without including sensitive technical details in a public message.

Include, when possible:

- the affected file, component, or commit;
- a concise impact assessment;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation;
- whether the issue may expose user records, logs, or research data.

The project does not currently promise a fixed response or remediation time. Please allow the maintainers time to reproduce and assess the report before public disclosure.

## Scope notes

- Questions about the SWRD dataset, access terms, or annotations are not software vulnerabilities.
- Model files and third-party dependencies may have their own security policies.
- Never submit real account files, local logs, or sensitive radiographic data as issue attachments.
